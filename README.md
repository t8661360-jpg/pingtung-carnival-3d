# 2026 屏東熟齡社團嘉年華：3D 場配模型

屏東縣立體育館東側草坪活動現場的 3D 模型，可在瀏覽器中自由走動，電腦和手機都能操作。

- 直接開啟 `index.html` 即可瀏覽（需連網載入 three.js r128）
- 可用 GitHub Pages 發布成網址

## 操作
- 電腦：WASD／方向鍵移動、拖曳轉視角、點地面自動走過去、點兩下傳送
- 手機：左下搖桿移動、右下轉向／抬頭低頭按鈕、點地面自動走過去；下方提示可關閉

## 資料來源
- 2026 熟齡社團嘉年華工作計劃書初稿
- 道路、樹木、建物位置依 Google 衛星圖量測（誤差約 ±3 m）；照片僅作建模參考
- 天空 HDRI：Poly Haven（CC0），經 @pmndrs/assets
